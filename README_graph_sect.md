# graph_sect.py - Визуализация структуры секций

Python-скрипт для извлечения и визуализации иерархии секций из SGML/XML документов.

## Описание

Скрипт извлекает все теги `<sect1>`, `<sect2>`, `<sect3>`, `<sect4>`, `<sect5>` (и их закрывающие теги) из файла и отображает их структуру с правильными отступами.

## Использование

### Базовый синтаксис

```bash
./graph_sect.py <файл.sgml> [опции]
```

### Опции

- **Без опций** - обычный вывод с отступами
- `-n`, `--numbers` - показывать номера строк
- `-c`, `--compact` - компактный вывод (только теги без атрибутов)
- `-t`, `--tree` - древовидная структура с символами дерева

## Как работает

1. **Читает файл** - открывает указанный SGML/XML файл
2. **Извлекает sect теги** - находит все строки с `<sect1>`, `<sect2>`, ... `<sect5>` и их закрывающие теги
3. **Определяет уровень** - извлекает номер секции (1-5)
4. **Удаляет отступы** - убирает все начальные пробелы и табуляции
5. **Добавляет отступы** - добавляет отступы по уровню:
   - `sect1` = 0 пробелов (без отступа)
   - `sect2` = 1 пробел
   - `sect3` = 2 пробела
   - `sect4` = 3 пробела
   - `sect5` = 4 пробела
6. **Сохраняет результат** - автоматически сохраняет в файл `sect.sgml` рядом со скриптом

## Форматы вывода

### Обычный режим (по умолчанию)

Показывает строки как есть, но с нормализованными отступами:

```
<sect1>
 <sect2>
  <sect3>
```

Отступы: sect1=0 пробелов, sect2=1 пробел, sect3=2 пробела и т.д.

### Компактный режим (-c)

Показывает только теги:

```
<sect1>
 <sect2>
  <sect3>
```

### Древовидный режим (-t)

Показывает структуру в виде дерева:

```
├─ sect1: Заголовок раздела
│ ├─ sect2: Подраздел
│ │ ├─ sect3: Подподраздел
```

### С номерами (-n)

Нумерует строки вывода:

```
  1: <sect1>
  2:  <sect2>
  3:   <sect3>
```

## Технические детали

### Регулярное выражение

Скрипт использует regex для поиска sect тегов:

```python
r'^.*?(</?sect[1-5][^>]*>).*$'
```

Находит:
- `<sect1>` - открывающие теги
- `</sect1>` - закрывающие теги
- `<sect1 id="intro">` - с атрибутами

### Определение уровня

```python
level_match = re.search(r'sect([1-5])', tag)
level = int(level_match.group(1))
```

Извлекает цифру из имени тега (1-5).

### Нормализация отступов

```python
clean_line = line.lstrip()      # Удаляем начальные пробелы
indent = ' ' * (level - 1)      # Добавляем отступ по уровню (sect1=0, sect2=1, ...)
print(f"{indent}{clean_line}")
```

## Troubleshooting

### Секции не найдены

**Проблема**: Вывод "⚠️ Секции не найдены в файле"

**Причины**:
1. В файле нет тегов `sect1`-`sect5`
2. Используются теги `section` или `refsect` (не поддерживаются)
3. Файл пустой или некорректный

**Решение**: Проверьте содержимое файла вручную.

### Файл не найден

**Проблема**: "❌ Файл не найден"

**Решение**: Проверьте путь к файлу:
```bash
ls -la your-file.sgml
```

### Неправильная кодировка

**Проблема**: Ошибки при чтении файла

**Решение**: Скрипт использует UTF-8. Если файл в другой кодировке, конвертируйте:
```bash
iconv -f WINDOWS-1251 -t UTF-8 file.sgml > file-utf8.sgml
```
